# Woblast

Woblast is a web app that helps you plan for retirement. It walks you through a guided wizard and projects month-by-month how your investments can grow toward your target income.

## Contribute

You need [Node.js](https://nodejs.org/) (current LTS) and npm installed.

```bash
npm install
```

Start the development server:

```bash
npm start
```

Run the test suite:

```bash
npm test
```

This project is written in TypeScript. To validate that the project compiles:

```bash
npm run tsc
```
